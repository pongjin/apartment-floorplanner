# 모바일 사용성·자동인식·업로드 품질 개선

- 날짜: 2026-08-30
- 관련 커밋: `ac8fed9`
- 커밋 제목: `feat: improve mobile planning and floor plan recognition`

## 배경과 목표

모바일에서 상·하단 UI가 도면을 가리거나 버튼이 겹쳤고, 3D 시점 이동에 두 손가락이 필요했습니다. 자동 벽 인식은 저해상도 도면에서 실패하거나 창과 문을 혼동했으며, 품질이 낮은 입력을 사전에 걸러내는 장치가 없었습니다. 모바일 편집 면적과 조작성을 개선하고, 자동인식의 입력·분류 단계와 결과 저장 흐름을 보완하는 것이 목표였습니다.

## 변경 내용

- 모바일 헤더, 단계 표시, 작업 패널과 하단 도구막대 크기 축소 및 겹침 해소
- 2D 도면 이동과 3D 시점 이동의 한 손가락 조작 개선
- 자동인식 완료 안내를 3초 후 자동으로 닫도록 변경
- 모바일 PNG 저장에 Web Share API를 적용하고 미지원 환경에는 다운로드 사용
- 자동인식에 도면 본체 영역 탐색, 컬러/선화 분기, 구조선 필터, 탐지 축척 분리 적용
- 작은 도면을 분석 전용 캔버스에서 확대한 뒤 원본 좌표로 복원
- 원호와 평행선 단서를 사용해 일반문·미닫이문·창 후보 분류
- 업로드 화면에 좋은 도면과 저해상도·흑백 도면 비교 가이드 추가
- 해상도·색상·대비·경계선 품질 검사 후 부적합 입력의 다음 단계 진입 차단

## 영향

- 부적합 이미지는 프로젝트에 저장되지 않으며 사용자는 첨부 단계에서 재선택해야 합니다.
- 품질 기준은 짧은 변 700px, 긴 변 1,100px, 약 90만 화소 이상입니다.
- 모바일 저장은 지원 기기에서 운영체제 공유창을 열고, 그 외 환경은 기존 다운로드 방식으로 동작합니다.
- 기존 IndexedDB 프로젝트 데이터 구조는 유지됩니다.

## 검증

- TypeScript `tsc -b` 통과
- Vite 프로덕션 빌드 통과
- 390×844 모바일 화면에서 가로 넘침 없음
- 5개 저해상도 도면 자동인식 반복 검증: 기존 3개 실패에서 5개 모두 처리 성공
- 217×148px 흑백 도면 업로드 차단 및 축척 단계 비활성 확인
- 3399×3403px 컬러 도면 업로드 통과 및 축척 단계 진입 확인
- 자동인식 처리 시간은 테스트 도면 기준 약 0.30~0.37초
