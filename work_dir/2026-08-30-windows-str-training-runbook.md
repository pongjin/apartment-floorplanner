# Windows FP/STR 학습·검증 실행서 작성

- 날짜: 2026-08-30
- 관련 커밋: 이 기록을 포함하는 커밋
- 커밋 제목: `docs: add Windows STR training runbook`

## 배경과 목표

자동인식 고도화 작업을 Windows RTX 4060 환경으로 이전할 때 새로운 프로젝트 경로와 AI Hub 데이터 경로만 제공해도 데이터 감사, 표본 추출, 학습, 평가, ONNX 변환과 웹 성능 검증을 같은 조건으로 재현할 수 있는 단일 실행 문서가 필요했습니다.

## 변경 내용

- `docs/WINDOWS_STR_TRAINING_RUNBOOK.md`에 제품 범위, FP/STR 라벨 정책, 2,000장 층화 표본 계획과 데이터 누수 방지 규칙을 정리했습니다.
- WSL2·CUDA 환경, 데이터 경로 계약, 새 Python 프로젝트 구조와 필수 CLI 인터페이스를 정의했습니다.
- 20장 overfit부터 250→1,500장 학습 곡선, 고정 test, ONNX/INT8, React 통합과 모바일·데스크톱 성능 테스트까지 단계별 합격 기준을 작성했습니다.
- `.gitignore`에 로컬 AI Hub Sample·dataset·학습 artifact 경로를 추가해 원본 데이터와 대용량 생성물이 실수로 추적되지 않게 했습니다.
- README와 작업 기록 인덱스에서 실행서로 이동할 수 있게 연결했습니다.

## 영향

런타임 코드와 사용자 데이터에는 영향이 없습니다. 후속 Windows 작업에서 구현 범위와 검증 기준의 기준 문서로 사용됩니다.

## 검증

- 기존 자동인식 로드맵, README, 커밋 기록 지침과 내용이 충돌하지 않는지 검토했습니다.
- AI Hub 공식 데이터 통계와 로컬 Sample에서 확인한 STR JSON의 `category_id`, `attributes`, segmentation 구조를 반영했습니다.
- 로컬 전용 실제 경로와 개인 도면을 문서에 포함하지 않고 placeholder로 작성했습니다.
- `Sample/` 내부 파일이 `.gitignore` 규칙으로 제외되고 스테이징 대상에 포함되지 않는지 확인했습니다.
- Markdown 링크와 코드 블록, 단계별 명령의 경로 일관성을 확인했습니다.

## 배포

문서와 데이터 보호 규칙을 커밋하고 `main`에 push하여 Vercel 자동 배포를 시작합니다. 런타임 코드는 바뀌지 않습니다.

## 남은 한계

- 문서가 정의한 Python 학습 패키지와 CLI는 Windows의 새 프로젝트에서 구현해야 합니다.
- RTX 4060 학습시간과 모바일 P50/P95는 목표 범위이며 실제 장비에서 측정 후 갱신해야 합니다.
- AI Hub 전체 archive의 실제 압축·폴더 구조는 다운로드 뒤 데이터 감사에서 다시 확인해야 합니다.
