# 하이브리드 평면도 자동 인식

## 제품 구조

자동 인식은 벽과 개구부의 책임을 분리한다.

1. `src/legacy/floorPlanDetectionHeuristic.ts`의 영상 처리 로직으로 직교 벽 그래프를 생성한다.
2. `public/models/hybrid-floorplan-lraspp-v1.onnx`를 브라우저에서 실행해 문·창 픽셀 후보와 확률을 얻는다.
3. 문은 AI 영역 중심에서 실제 유한 벽 선분까지의 거리로 부모 벽을 선택한다.
4. 창은 길쭉한 영역의 방향을 유지해 같은 방향 벽 축에 부착한다. 벽의 창 구간이 비어 있어도 양쪽 벽 조각의 축을 사용할 수 있다.
5. 벽 범위 밖, 벽에서 먼 후보, 짧은 고립 창, 낮은 확률의 코너 창을 제거한다.

벽은 휴리스틱 결과이므로 확률이 없다. 문·창에만 AI 분류명과 평균 확률을 저장하고 화면에 표시한다.

## 모델

| 항목 | 값 |
| --- | --- |
| 구조 | LRASPP MobileNet V3 Large |
| 입력 | RGB 640×480 letterbox, ImageNet 정규화 |
| 출력 | 9-class semantic logits |
| 학습 | AI Hub 건축 도면 STR, 층화 추출 1,500장 전이학습 |
| validation mean IoU | 0.4198 |
| ONNX opset | 18 |
| 모델 크기 | 약 13.1MB |

배포 모델 SHA-256은 `95B95B3F7791F531768BCFBA31D4013BC7E4C24B899BFFE4A43F6DDC0E0C3835`, ONNX WASM SHA-256은 `71AEF04959C5C1B6DE461B6538E2058E306610034A85AAD2742D0C7FD4533FE4`다.

클래스는 배경, 철근콘크리트벽, 기타벽, 여닫이문, 미닫이문, 기타문, 여닫이창, 미닫이창, 기타창 순서다. 제품은 AI 벽 클래스는 사용하지 않고 문·창 클래스 3~8만 사용한다.

## 개인정보와 실행 환경

- 모델과 WASM을 내려받은 뒤 추론은 브라우저에서 실행한다.
- 사용자가 올린 도면은 추론을 위해 서버로 전송하지 않는다.
- WASM 단일 스레드로 실행해 별도 cross-origin isolation 헤더 없이 모바일 브라우저에서도 동작하도록 구성했다. 런타임 바이너리와 동적 MJS 로더는 `/ort/`에서 함께 제공한다.
- 첫 실행은 약 24MB 정적 자산 다운로드가 필요하며 이후에는 브라우저 캐시 효과를 받는다.

## 레거시와 롤백

이전 휴리스틱-only 구현은 `src/legacy/floorPlanDetectionHeuristic.ts`에 보존한다. 긴급 롤백 시 `src/App.tsx`의 동적 import 대상을 레거시 모듈로 바꾸거나 새 진입점에서 `detectFloorPlanLegacy`를 사용할 수 있다.

## 알려진 한계

- validation 픽셀 지표는 서비스 도면의 객체 단위 정확도를 보장하지 않는다.
- 저해상도·압축·공급처 차이가 큰 도면에서는 문 과검출과 창 누락이 남을 수 있다.
- 벽은 계속 휴리스틱이므로 치수선·가구선이 강한 도면에서 구조선 오탐이 가능하다.
- 사용자는 자동 후보를 편집 화면에서 삭제하거나 직접 다시 그릴 수 있어야 한다.
